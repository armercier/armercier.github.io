##### About the talk

How a Python FWI framework, built by the Mathematical Geophysics group at ETH Zurich with the start-up Mondaic AG, balances research flexibility with software-engineering practice. The focus is on integration tests that run complete inversion pipelines on benchmark problems, so that new features and performance work cannot silently change scientific results.
